# tmpl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `tmpl`, a single-binary Go CLI that copies a project template
(by short name, GitHub path, or local path) into a directory, fills in the
project name, and hands off to Claude for setup. Ship it with the author's
templates and a Homebrew release pipeline.

**Architecture:** `cmd/tmpl` parses arguments and wires five small internal
packages in a straight line: `source` (argument → location), `fetch`
(location → in-memory files), `rename` (`{{name}}` substitution), `write`
(files → disk, no-overwrite), `setup` (Claude handoff). `catalog` supports
`tmpl list`. Templates live in `templates/` in the same repo.

**Tech Stack:** Go (standard library only, `go 1.24` in go.mod, Go 1.27
locally), GoReleaser v2, GitHub Actions, Homebrew tap `wsoule/homebrew-tap`.

**Spec:** `docs/superpowers/specs/2026-10-09-tmpl-design.md`

## Global Constraints

- Module path: `github.com/wsoule/tmpl`. Binary name: `tmpl`.
- No third-party Go dependencies.
- Default template repo: `wsoule/tmpl`, overridden by the `TMPL_REPO` env var.
- Placeholder token: the literal `{{name}}`.
- Project names must match `^[a-z0-9][a-z0-9._-]*$`.
- Exit codes: `0` success, `1` usage error, `2` source not found, `3` other failure.
- Always skip `.git/`, `node_modules/`, `.DS_Store`; never write `tmpl.json` into projects.
- Never overwrite existing files without `--force`.
- Setup skill path: `.agents/skills/setup/SKILL.md`. Claude prompt string:
  `Follow .agents/skills/setup/SKILL.md to finish setting up this project.`
- Targets: darwin/linux × amd64/arm64, `CGO_ENABLED=0`. No Windows.
- Every commit message ends with
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

### Deviations from the spec (intentional)

- The spec's `internal/copy` package is named `internal/write`, because a
  package named `copy` shadows Go's builtin `copy`.
- With a token, GitHub downloads use `api.github.com/repos/<o>/<r>/tarball/<ref>`
  (which redirects to a signed codeload URL) instead of codeload with a bearer
  header, because the API endpoint is the documented way to fetch private
  tarballs. Anonymous downloads still use codeload. A `401` with a token is
  retried anonymously, so a stale `gh` login doesn't break public templates.
- The `{{name}}` prompt only appears when at least one template file contains
  `{{name}}`.
- The default project name is the dest folder name *normalized* to a valid
  name (`Dogear` → `dogear`), not validated, so running in a folder with
  capital letters isn't an error. An explicit `--name` is still validated
  strictly.

## Review Focus

1. **Running in a non-empty folder** (e.g. `~/Sites/Dogear` already has a spec
   `.md`): existing files are kept and listed, everything else is written,
   and the exit code is 0. Tested in Task 5 and Task 7.
2. **Folder names that aren't valid package names** (`Dogear`, `My App`): the
   default name is normalized silently (`dogear`, `my-app`) and is never an
   error. Tested in Task 4 and Task 7.
3. **Non-interactive stdin** (piped, CI, an agent harness): no prompt is ever
   shown and nothing blocks waiting for input. Tested in Task 6 and Task 7.
4. **A typo or missing template**: exit 2 with `template "<x>" not found`, and
   the dest folder is *not* created. Tested in Task 7.
5. **Refs containing slashes** (`owner/repo/sub@feature/x`): ref is
   `feature/x` and subdir is `sub`, not the other way round. Tested in Task 1.

```go
// Package source turns the <source> argument a user types into a concrete
// template location: a local directory or a path inside a GitHub repo.
package source

import (
	"errors"
	"fmt"
	"os"
	"path"
	"path/filepath"
	"regexp"
	"strings"
)

type Kind int

const (
	Local Kind = iota
	GitHub
)

type Source struct {
	Kind   Kind
	Path   string // Local: absolute directory
	Owner  string // GitHub
	Repo   string // GitHub
	Subdir string // GitHub: slash-separated path inside the repo, "" for root
	Ref    string // GitHub: branch/tag/sha, "" for the default branch
	Bare   bool   // true when the user typed a bare template name
}

type Options struct {
	Cwd         string // resolves relative local paths
	Home        string // expands "~"
	DefaultRepo string // "owner/repo[/path][@ref]" that bare names resolve into
}

// DefaultRepo is where bare template names live unless TMPL_REPO is set.
const DefaultRepo = "wsoule/tmpl"

var bareName = regexp.MustCompile(`^[A-Za-z0-9][A-Za-z0-9._-]*$`)

// RepoFromEnv returns the repo bare names resolve into: TMPL_REPO, or DefaultRepo.
func RepoFromEnv() string {
	if v := strings.TrimSpace(os.Getenv("TMPL_REPO")); v != "" {
		return v
	}
	return DefaultRepo
}

// Parse resolves a source string. Order: local path, then GitHub path
// (anything with a "/"), then bare name inside o.DefaultRepo's templates/.
func Parse(raw string, o Options) (Source, error) {
	s := strings.TrimSpace(raw)
	if s == "" {
		return Source{}, errors.New("empty template source")
	}
	if p, ok := localPath(s, o); ok {
		if p == string(filepath.Separator) {
			return Source{}, fmt.Errorf("invalid template source %q", raw)
		}
		return Source{Kind: Local, Path: p}, nil
	}
	if strings.Contains(s, "/") {
		return parseGitHub(s)
	}
	if !bareName.MatchString(s) {
		return Source{}, fmt.Errorf("invalid template name %q", s)
	}
	src, err := Templates(o.DefaultRepo)
	if err != nil {
		return Source{}, err
	}
	src.Subdir = path.Join(src.Subdir, s)
	src.Bare = true
	return src, nil
}

// Templates returns the templates/ directory of a default repo string.
func Templates(defaultRepo string) (Source, error) {
	src, err := parseGitHub(defaultRepo)
	if err != nil {
		return Source{}, fmt.Errorf("invalid template repo %q (set TMPL_REPO to owner/repo): %w", defaultRepo, err)
	}
	src.Subdir = path.Join(src.Subdir, "templates")
	return src, nil
}

// localPath reports whether s names a local directory, returning its absolute path.
// Explicit path prefixes always count; a bare word counts only if that directory exists.
func localPath(s string, o Options) (string, bool) {
	switch {
	case s == "~" || strings.HasPrefix(s, "~/"):
		return filepath.Join(o.Home, s[1:]), true
	case filepath.IsAbs(s):
		return filepath.Clean(s), true
	case s == "." || s == ".." || strings.HasPrefix(s, "./") || strings.HasPrefix(s, "../"):
		return filepath.Join(o.Cwd, s), true
	}
	p := filepath.Join(o.Cwd, s)
	if fi, err := os.Stat(p); err == nil && fi.IsDir() {
		return p, true
	}
	return "", false
}

// parseGitHub parses "owner/repo[/path][@ref]", with an optional
// "https://github.com/" or "github.com/" prefix. The ref is everything after
// the first "@", so refs may contain slashes.
func parseGitHub(s string) (Source, error) {
	s = strings.TrimPrefix(s, "https://")
	s = strings.TrimPrefix(s, "github.com/")
	ref := ""
	if i := strings.Index(s, "@"); i >= 0 {
		s, ref = s[:i], s[i+1:]
		if ref == "" {
			return Source{}, errors.New("empty ref after @")
		}
	}
	parts := strings.Split(strings.Trim(s, "/"), "/")
	if len(parts) < 2 || parts[0] == "" || parts[1] == "" {
		return Source{}, fmt.Errorf("expected owner/repo[/path][@ref], got %q", s)
	}
	for _, p := range parts[2:] {
		if p == "" || p == "." || p == ".." {
			return Source{}, fmt.Errorf("invalid path in %q", s)
		}
	}
	return Source{
		Kind:   GitHub,
		Owner:  parts[0],
		Repo:   parts[1],
		Subdir: strings.Join(parts[2:], "/"),
		Ref:    ref,
	}, nil
}
```

```go
// tarball builds a gzipped tar in memory, the same shape GitHub serves.
func tarball(t *testing.T, entries []entry) *bytes.Buffer {
	t.Helper()
	var buf bytes.Buffer
	gz := gzip.NewWriter(&buf)
	tw := tar.NewWriter(gz)
	for _, e := range entries {
		typ := e.typ
		if typ == 0 {
			typ = tar.TypeReg
		}
		mode := e.mode
		if mode == 0 {
			mode = 0o644
		}
		h := &tar.Header{Name: e.name, Typeflag: typ, Mode: mode, Linkname: e.link, Size: int64(len(e.body))}
		if typ != tar.TypeReg {
			h.Size = 0
		}
		if typ == tar.TypeXGlobalHeader {
			// GitHub tarballs start with one of these; it may only carry PAX records.
			h = &tar.Header{Name: e.name, Typeflag: typ, PAXRecords: map[string]string{"comment": "abc123"}}
		}
		if err := tw.WriteHeader(h); err != nil {
			t.Fatal(err)
		}
		if typ == tar.TypeReg {
			if _, err := tw.Write([]byte(e.body)); err != nil {
				t.Fatal(err)
			}
		}
	}
	if err := tw.Close(); err != nil {
		t.Fatal(err)
	}
	if err := gz.Close(); err != nil {
		t.Fatal(err)
	}
	return &buf
}
```

```go
// Package fetch loads a template's files into memory from a local directory
// or a GitHub tarball, dropping anything unsafe or never-copied on the way.
package fetch

import (
	"errors"
	"io/fs"
	"path"
	"strings"
)

// File is one template file held in memory.
type File struct {
	Path       string      // slash-separated, relative to the template root
	Mode       fs.FileMode // permission bits only
	Data       []byte      // nil for symlinks
	LinkTarget string      // non-empty for symlinks
}

// Result is a fetched template plus non-fatal problems (skipped entries).
type Result struct {
	Files    []File
	Warnings []string
}

// ErrNotFound means the source exists nowhere or contains no files.
var ErrNotFound = errors.New("template not found")

// Ignored reports whether a path must never be copied into a project:
// anything inside .git or node_modules, and macOS .DS_Store files.
func Ignored(rel string) bool {
	for _, seg := range strings.Split(rel, "/") {
		if seg == ".git" || seg == "node_modules" || seg == ".DS_Store" {
			return true
		}
	}
	return false
}

// cleanRel normalizes a slash-separated relative path and rejects paths that
// are empty, absolute, or climb out of the template root with "..".
func cleanRel(p string) (string, bool) {
	if p == "" || path.IsAbs(p) {
		return "", false
	}
	c := path.Clean(p)
	if c == "." || c == ".." || strings.HasPrefix(c, "../") {
		return "", false
	}
	return c, true
}

// linkStaysInside reports whether a symlink stored at rel and pointing at
// target resolves to somewhere inside the template root.
func linkStaysInside(rel, target string) bool {
	if path.IsAbs(target) {
		return false
	}
	_, ok := cleanRel(path.Join(path.Dir(rel), target))
	return ok
}
```

```go
package fetch

import (
	"archive/tar"
	"compress/gzip"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"strings"
)

// ExtractTarGz reads a GitHub-style .tar.gz (everything under one top-level
// "<repo>-<sha>/" directory) and returns the files under subdir, with that
// prefix stripped. An empty result is ErrNotFound.
func ExtractTarGz(r io.Reader, subdir string) (Result, error) {
	gz, err := gzip.NewReader(r)
	if err != nil {
		return Result{}, fmt.Errorf("read tarball: %w", err)
	}
	defer gz.Close()

	prefix := ""
	if s := strings.Trim(subdir, "/"); s != "" {
		prefix = s + "/"
	}

	var res Result
	tr := tar.NewReader(gz)
	for {
		h, err := tr.Next()
		if errors.Is(err, io.EOF) {
			break
		}
		// With GODEBUG=tarinsecurepath=0, Next reports ".." names as
		// ErrInsecurePath but still returns a valid header; cleanRel below
		// rejects those entries, so keep reading.
		if err != nil && !errors.Is(err, tar.ErrInsecurePath) {
			return Result{}, fmt.Errorf("read tarball: %w", err)
		}
		if h.Typeflag == tar.TypeXGlobalHeader || h.Typeflag == tar.TypeXHeader {
			continue
		}
		i := strings.Index(h.Name, "/")
		if i < 0 {
			continue
		}
		name := h.Name[i+1:]
		if prefix != "" {
			if !strings.HasPrefix(name, prefix) {
				continue
			}
			name = name[len(prefix):]
		}
		if name == "" || h.Typeflag == tar.TypeDir {
			continue
		}
		rel, ok := cleanRel(name)
		if !ok {
			res.Warnings = append(res.Warnings, fmt.Sprintf("skipped unsafe path %q", h.Name))
			continue
		}
		if Ignored(rel) {
			continue
		}
		switch h.Typeflag {
		case tar.TypeReg:
			data, err := io.ReadAll(tr)
			if err != nil {
				return Result{}, fmt.Errorf("read %s: %w", rel, err)
			}
			res.Files = append(res.Files, File{Path: rel, Mode: fs.FileMode(h.Mode).Perm(), Data: data})
		case tar.TypeSymlink:
			if !linkStaysInside(rel, h.Linkname) {
				res.Warnings = append(res.Warnings, fmt.Sprintf("skipped symlink %s -> %s (points outside the template)", rel, h.Linkname))
				continue
			}
			res.Files = append(res.Files, File{Path: rel, Mode: 0o777, LinkTarget: h.Linkname})
		default:
			res.Warnings = append(res.Warnings, fmt.Sprintf("skipped special file %s", rel))
		}
	}
	if len(res.Files) == 0 {
		return Result{}, ErrNotFound
	}
	return res, nil
}
```

```go
package fetch

import (
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

// Local reads a template directory from disk, applying the same skip and
// symlink rules as tarball extraction.
func Local(root string) (Result, error) {
	fi, err := os.Stat(root)
	if err != nil || !fi.IsDir() {
		return Result{}, fmt.Errorf("%w: %s", ErrNotFound, root)
	}
	var res Result
	err = filepath.WalkDir(root, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if p == root {
			return nil
		}
		relOS, err := filepath.Rel(root, p)
		if err != nil {
			return err
		}
		rel := filepath.ToSlash(relOS)
		if Ignored(rel) {
			if d.IsDir() {
				return filepath.SkipDir
			}
			return nil
		}
		switch {
		case d.IsDir():
			return nil
		case d.Type()&fs.ModeSymlink != 0:
			target, err := os.Readlink(p)
			if err != nil {
				return err
			}
			target = filepath.ToSlash(target)
			if !linkStaysInside(rel, target) {
				res.Warnings = append(res.Warnings, fmt.Sprintf("skipped symlink %s -> %s (points outside the template)", rel, target))
				return nil
			}
			res.Files = append(res.Files, File{Path: rel, Mode: 0o777, LinkTarget: target})
		case d.Type().IsRegular():
			info, err := d.Info()
			if err != nil {
				return err
			}
			data, err := os.ReadFile(p)
			if err != nil {
				return err
			}
			res.Files = append(res.Files, File{Path: rel, Mode: info.Mode().Perm(), Data: data})
		default:
			res.Warnings = append(res.Warnings, fmt.Sprintf("skipped special file %s", rel))
		}
		return nil
	})
	if err != nil {
		return Result{}, fmt.Errorf("read %s: %w", root, err)
	}
	if len(res.Files) == 0 {
		return Result{}, fmt.Errorf("%w: %s is empty", ErrNotFound, root)
	}
	return res, nil
}
```

```go
package fetch

import (
	"context"
	"errors"
	"fmt"
	"net/http"
	"os"
	"os/exec"
	"strings"
	"time"

	"github.com/wsoule/tmpl/internal/source"
)

// GitHub downloads repository tarballs. Anonymous requests go to codeload;
// with a token they go to the API's tarball endpoint so private repos work.
type GitHub struct {
	Client      *http.Client
	CodeloadURL string
	APIURL      string
	Token       string
}

// NewGitHub returns a fetcher pointed at github.com.
func NewGitHub(token string) *GitHub {
	return &GitHub{
		Client:      &http.Client{Timeout: 2 * time.Minute},
		CodeloadURL: "https://codeload.github.com",
		APIURL:      "https://api.github.com",
		Token:       token,
	}
}

// Fetch downloads owner/repo at ref ("" = default branch) and returns the
// files under subdir.
func (g *GitHub) Fetch(ctx context.Context, owner, repo, ref, subdir string) (Result, error) {
	res, status, err := g.fetch(ctx, owner, repo, ref, subdir, g.Token)
	if status == http.StatusUnauthorized && g.Token != "" {
		// A stale token shouldn't break public templates.
		res, _, err = g.fetch(ctx, owner, repo, ref, subdir, "")
	}
	return res, err
}

func (g *GitHub) fetch(ctx context.Context, owner, repo, ref, subdir, token string) (Result, int, error) {
	var url string
	if token != "" {
		url = fmt.Sprintf("%s/repos/%s/%s/tarball", g.APIURL, owner, repo)
		if ref != "" {
			url += "/" + ref
		}
	} else {
		r := ref
		if r == "" {
			r = "HEAD"
		}
		url = fmt.Sprintf("%s/%s/%s/tar.gz/%s", g.CodeloadURL, owner, repo, r)
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
	if err != nil {
		return Result{}, 0, err
	}
	req.Header.Set("User-Agent", "tmpl")
	if token != "" {
		req.Header.Set("Authorization", "Bearer "+token)
	}
	resp, err := g.Client.Do(req)
	if err != nil {
		return Result{}, 0, fmt.Errorf("download %s/%s: %w", owner, repo, err)
	}
	defer resp.Body.Close()

	switch resp.StatusCode {
	case http.StatusOK:
	case http.StatusNotFound:
		return Result{}, resp.StatusCode, fmt.Errorf("%w: github.com/%s/%s", ErrNotFound, owner, repo)
	default:
		return Result{}, resp.StatusCode, fmt.Errorf("download %s/%s: unexpected status %s", owner, repo, resp.Status)
	}
	res, err := ExtractTarGz(resp.Body, subdir)
	if errors.Is(err, ErrNotFound) {
		return Result{}, resp.StatusCode, fmt.Errorf("%w: %s/%s/%s", ErrNotFound, owner, repo, subdir)
	}
	return res, resp.StatusCode, err
}

// TokenFromEnv returns a GitHub token from GITHUB_TOKEN or `gh auth token`,
// or "" when neither is available. It never fails.
func TokenFromEnv() string {
	if t := strings.TrimSpace(os.Getenv("GITHUB_TOKEN")); t != "" {
		return t
	}
	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()
	out, err := exec.CommandContext(ctx, "gh", "auth", "token").Output()
	if err != nil {
		return ""
	}
	return strings.TrimSpace(string(out))
}

// Fetch loads the template a parsed source points at.
func Fetch(ctx context.Context, src source.Source, gh *GitHub) (Result, error) {
	switch src.Kind {
	case source.Local:
		return Local(src.Path)
	case source.GitHub:
		return gh.Fetch(ctx, src.Owner, src.Repo, src.Ref, src.Subdir)
	default:
		return Result{}, fmt.Errorf("unknown source kind %d", src.Kind)
	}
}
```

```go
// Package rename fills the project name into template files by replacing
// the literal {{name}} token.
package rename

import (
	"bytes"
	"fmt"
	"regexp"
	"strings"

	"github.com/wsoule/tmpl/internal/fetch"
)

// Token is the placeholder template authors put where the project name goes.
const Token = "{{name}}"

var valid = regexp.MustCompile(`^[a-z0-9][a-z0-9._-]*$`)

// Validate checks that name is safe to use as a package name.
func Validate(name string) error {
	if !valid.MatchString(name) {
		return fmt.Errorf("invalid project name %q: use lowercase letters, digits, '.', '_' or '-' (try %q)", name, Suggest(name))
	}
	return nil
}

// Suggest turns an arbitrary string, usually a folder name, into a valid
// project name: lowercase, other characters replaced by '-', no leading
// punctuation. Falls back to "app".
func Suggest(s string) string {
	var b strings.Builder
	for _, r := range strings.ToLower(s) {
		switch {
		case r >= 'a' && r <= 'z', r >= '0' && r <= '9', r == '.', r == '_', r == '-':
			b.WriteRune(r)
		default:
			b.WriteRune('-')
		}
	}
	out := strings.TrimLeft(b.String(), "._-")
	if out == "" {
		return "app"
	}
	return out
}

// IsText reports whether data looks like text: no NUL byte in the first 8 KB.
func IsText(data []byte) bool {
	return !bytes.Contains(data[:min(len(data), 8192)], []byte{0})
}

// Uses reports whether any text file contains Token.
func Uses(files []fetch.File) bool {
	for _, f := range files {
		if f.LinkTarget == "" && IsText(f.Data) && bytes.Contains(f.Data, []byte(Token)) {
			return true
		}
	}
	return false
}

// Apply replaces Token with name in every text file, in place, and returns
// the paths it changed. Symlinks and binary files are left alone.
func Apply(files []fetch.File, name string) []string {
	var changed []string
	tok, repl := []byte(Token), []byte(name)
	for i := range files {

			continue
		}
		f.Data = bytes.ReplaceAll(f.Data, tok, repl)
		changed = append(changed, f.Path)
	}
	return changed
}
```

```go
// Package write puts fetched template files on disk without clobbering
// anything the user already has, unless forced.
package write

import (
	"fmt"
	"os"
	"path/filepath"

	"github.com/wsoule/tmpl/internal/fetch"
)

// ManifestFile is the template's own metadata; it is never written into projects.
const ManifestFile = "tmpl.json"

// Report lists what happened to each template file.
type Report struct {
	Written []string // paths created or overwritten
	Kept    []string // paths that already existed and were left alone
}

// Files writes files under dest, creating dest if needed. Existing paths are
// kept unless force is set, in which case they are replaced. A directory in
// the way of a file is an error even with force, so nothing is deleted recursively.
func Files(dest string, files []fetch.File, force bool) (Report, error) {
	if err := os.MkdirAll(dest, 0o755); err != nil {
		return Report{}, err
	}
	var rep Report
	for _, f := range files {
		if f.Path == ManifestFile {
			continue
		}
		target := filepath.Join(dest, filepath.FromSlash(f.Path))
		if _, err := os.Lstat(target); err == nil {
			if !force {
				rep.Kept = append(rep.Kept, f.Path)
				continue
			}
			if err := os.Remove(target); err != nil {
				return rep, fmt.Errorf("replace %s: %w", f.Path, err)
			}
		}
		if err := os.MkdirAll(filepath.Dir(target), 0o755); err != nil {
			return rep, err
		}
		if f.LinkTarget != "" {
			if err := os.Symlink(filepath.FromSlash(f.LinkTarget), target); err != nil {
				return rep, err
			}
		} else {
			mode := f.Mode
			if mode == 0 {
				mode = 0o644
			}
			if err := os.WriteFile(target, f.Data, mode); err != nil {
				return rep, err
			}
			// WriteFile's mode is masked by the umask; set it exactly.
			if err := os.Chmod(target, mode); err != nil {
				return rep, err
			}
		}
		rep.Written = append(rep.Written, f.Path)
	}
	return rep, nil
}
```

```go
// Package catalog turns the contents of a templates/ directory into the
// list `tmpl list` prints.
package catalog

import (
	"encoding/json"
	"sort"
	"strings"

	"github.com/wsoule/tmpl/internal/fetch"
)

// Entry is one template: its directory name and optional description.
type Entry struct {
	Name        string
	Description string
}

// List returns one entry per top-level directory in files, sorted by name.
// Descriptions come from each template's tmpl.json; unreadable manifests are ignored.
func List(files []fetch.File) []Entry {
	desc := map[string]string{}
	seen := map[string]bool{}
	for _, f := range files {
		i := strings.Index(f.Path, "/")
		if i < 0 {
			continue
		}
		name := f.Path[:i]
		seen[name] = true
		if f.Path[i+1:] == "tmpl.json" {
			var m struct {
				Description string `json:"description"`
			}
			if json.Unmarshal(f.Data, &m) == nil {
				desc[name] = m.Description
			}
		}
	}
	entries := make([]Entry, 0, len(seen))
	for name := range seen {
		entries = append(entries, Entry{Name: name, Description: desc[name]})
	}
	sort.Slice(entries, func(a, b int) bool { return entries[a].Name < entries[b].Name })
	return entries
}
```

```go
package setup

	"os"
	"path/filepath"
	"strings"

// SkillPath is where templates put plain-English setup steps for Claude.
const SkillPath = ".agents/skills/setup/SKILL.md"

// Prompt is the instruction passed to Claude.
const Prompt = "Follow .agents/skills/setup/SKILL.md to finish setting up this project."

type Options struct {
	Dest        string // absolute project directory
	ShownDest   string // dest as the user typed it, for printed hints
	Interactive bool
	In          *bufio.Reader
	Out         io.Writer
	LookPath    func(string) (string, error)
	Chdir       func(string) error
	Exec        func(argv0 string, argv []string, env []string) error
}

// Run offers to start Claude in the project when the template has a setup
// skill. Interactive with claude installed: ask, and on yes replace this
// process with claude. Otherwise: print the command to run next.
func Run(o Options) error {
	if _, err := os.Stat(filepath.Join(o.Dest, filepath.FromSlash(SkillPath))); err != nil {
		return nil
	}
	if claude, err := o.LookPath("claude"); err == nil && o.Interactive {
		fmt.Fprint(o.Out, "Run Claude to finish setup? [Y/n] ")
		line, readErr := o.In.ReadString('\n')
		ans := strings.ToLower(strings.TrimSpace(line))
		eof := readErr != nil && line == ""
		if !eof && (ans == "" || ans == "y" || ans == "yes") {
			if err := o.Chdir(o.Dest); err != nil {
				return err
			}
			return o.Exec(claude, []string{"claude", Prompt}, os.Environ())
		}
	}
	fmt.Fprintln(o.Out, "Next: "+Hint(o.ShownDest))
	return nil
}

// Hint is the shell command that starts Claude on the project's setup skill.
func Hint(shownDest string) string {
	cmd := fmt.Sprintf("claude %q", Prompt)
	if shownDest == "" || shownDest == "." {
		return cmd
	}
	if strings.ContainsAny(shownDest, " \t'\"$") {
		shownDest = fmt.Sprintf("%q", shownDest)
	}
	return fmt.Sprintf("cd %s && %s", shownDest, cmd)
}
```

```go
package main

import (
	"errors"
	"fmt"
	"strings"
)

type args struct {
	cmd     string // "copy", "list", "version", "help"
	source  string
	dest    string
	name    string
	force   bool
	noSetup bool
	yes     bool
}

// parseArgs accepts flags before or after positional arguments
// (`tmpl pierre . --force`), which the standard flag package does not.
func parseArgs(argv []string) (args, error) {
	var a args
	var pos []string
	for i := 0; i < len(argv); i++ {
		arg := argv[i]
		if arg == "--" {
			pos = append(pos, argv[i+1:]...)
			break
		}
		if !strings.HasPrefix(arg, "-") || arg == "-" {
			pos = append(pos, arg)
			continue
		}
		name, value, hasValue := strings.Cut(arg, "=")
		switch name {
		case "-n", "--name":
			if !hasValue {
				if i+1 >= len(argv) {
					return args{}, errors.New("--name needs a value")
				}
				i++
				value = argv[i]
			}
			a.name = value
		case "-f", "--force":
			a.force = true
		case "--no-setup":
			a.noSetup = true
		case "-y", "--yes":
			a.yes = true
		case "-h", "--help":
			return args{cmd: "help"}, nil
		case "-v", "--version":
			return args{cmd: "version"}, nil
		default:
			return args{}, fmt.Errorf("unknown flag %s", arg)
		}
	}

	if len(pos) == 1 {
		switch pos[0] {
		case "list", "version", "help":
			return args{cmd: pos[0]}, nil
		}
	}
	if len(pos) > 0 && pos[0] == "list" {
		return args{}, errors.New("list takes no arguments")
	}
	switch len(pos) {
	case 0:
		return args{}, errors.New("missing template source")
	case 1:
		a.source, a.dest = pos[0], "."
	case 2:
		a.source, a.dest = pos[0], pos[1]
	default:
		return args{}, errors.New("too many arguments")
	}
	a.cmd = "copy"
	return a, nil
}
```

```go
// Command tmpl copies a project template into a directory.
package main

import (
	"bufio"
	"context"
	"errors"
	"fmt"
	"io"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
	"syscall"
	"text/tabwriter"

	"github.com/wsoule/tmpl/internal/catalog"
	"github.com/wsoule/tmpl/internal/fetch"
	"github.com/wsoule/tmpl/internal/rename"
	"github.com/wsoule/tmpl/internal/setup"
	"github.com/wsoule/tmpl/internal/source"
	"github.com/wsoule/tmpl/internal/write"
)

// Version is set at release time with -ldflags "-X main.Version=...".
var Version = "dev"

const (
	exitOK       = 0
	exitUsage    = 1
	exitNotFound = 2
	exitFail     = 3
)

const usage = `usage:
  tmpl <source> [dest]   copy a template into dest (default ".")
  tmpl list              list templates in the default repo
  tmpl version

source:
  pierre                      a template in $TMPL_REPO (default wsoule/tmpl)
  owner/repo[/path][@ref]     any GitHub repo or folder in one
  ./path  ~/path  /path       a local directory

flags:
  -n, --name <name>   project name for {{name}} (default: dest folder name)
  -f, --force         overwrite existing files
      --no-setup      don't offer to run Claude afterwards
  -y, --yes           never prompt
`

func main() {
	os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))
}

// run is main without os.Exit, so tests can call it in-process.
func run(argv []string, stdin *os.File, stdout, stderr io.Writer) int {
	a, err := parseArgs(argv)
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n\n%s", err, usage)
		return exitUsage
	}
	switch a.cmd {
	case "help":
		fmt.Fprint(stdout, usage)
		return exitOK
	case "version":
		fmt.Fprintln(stdout, "tmpl "+Version)
		return exitOK
	case "list":
		return runList(stdout, stderr)
	}
	return runCopy(a, stdin, stdout, stderr)
}

func runCopy(a args, stdin *os.File, stdout, stderr io.Writer) int {
	ctx := context.Background()
	cwd, err := os.Getwd()
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		return exitFail
	}
	home, _ := os.UserHomeDir()

	if a.name != "" {
		if err := rename.Validate(a.name); err != nil {
			fmt.Fprintf(stderr, "tmpl: %v\n", err)
			return exitUsage
		}
	}

	src, err := source.Parse(a.source, source.Options{Cwd: cwd, Home: home, DefaultRepo: source.RepoFromEnv()})
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		return exitUsage
	}

	gh := fetch.NewGitHub("")
	if src.Kind == source.GitHub {
		gh.Token = fetch.TokenFromEnv()
	}
	res, err := fetch.Fetch(ctx, src, gh)
	if errors.Is(err, fetch.ErrNotFound) {
		fmt.Fprintf(stderr, "tmpl: template %q not found\n", a.source)
		if src.Bare {
			fmt.Fprintln(stderr, "\navailable templates:")
			runList(stderr, io.Discard)
		}
		return exitNotFound
	}
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		return exitFail
	}
	for _, w := range res.Warnings {
		fmt.Fprintf(stderr, "tmpl: warning: %s\n", w)
	}

	dest := a.dest
	if !filepath.IsAbs(dest) {
		dest = filepath.Join(cwd, dest)
	}
	interactive := !a.yes && isTerminal(stdin)
	in := bufio.NewReader(stdin)

	if rename.Uses(res.Files) {
		name, err := projectName(a.name, dest, interactive, in, stdout)
		if err != nil {
			fmt.Fprintf(stderr, "tmpl: %v\n", err)
			return exitUsage
		}
		rename.Apply(res.Files, name)
	}

	rep, err := write.Files(dest, res.Files, a.force)
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		return exitFail
	}
	fmt.Fprintf(stdout, "Created %s from %s (%d files)\n", a.dest, a.source, len(rep.Written))
	if len(rep.Kept) > 0 {
		fmt.Fprintf(stdout, "Kept %d existing files (use --force to overwrite):\n", len(rep.Kept))
		for _, p := range rep.Kept {
			fmt.Fprintf(stdout, "  %s\n", p)
		}
	}

	if !a.noSetup {
		err := setup.Run(setup.Options{
			Dest: dest, ShownDest: a.dest, Interactive: interactive,
			In: in, Out: stdout,
			LookPath: exec.LookPath, Chdir: os.Chdir, Exec: syscall.Exec,
		})
		if err != nil {
			fmt.Fprintf(stderr, "tmpl: %v\n", err)
			return exitFail
		}
	}
	return exitOK
}

// projectName decides what replaces {{name}}: the --name flag, else the
// user's answer to a prompt, else the dest folder name normalized to a valid name.
func projectName(flag, dest string, interactive bool, in *bufio.Reader, out io.Writer) (string, error) {
	if flag != "" {
		return flag, nil // validated before fetching
	}
	def := rename.Suggest(filepath.Base(dest))
	if !interactive {
		return def, nil
	}
	for {
		fmt.Fprintf(out, "Project name (%s): ", def)
		line, readErr := in.ReadString('\n')
		name := strings.TrimSpace(line)
		if name == "" {
			return def, nil
		}
		if err := rename.Validate(name); err != nil {
			if readErr != nil {
				return "", err
			}
			fmt.Fprintln(out, err)
			continue
		}
		return name, nil
	}
}

func runList(stdout, stderr io.Writer) int {
	src, err := source.Templates(source.RepoFromEnv())
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		return exitUsage
	}
	res, err := fetch.NewGitHub(fetch.TokenFromEnv()).Fetch(context.Background(), src.Owner, src.Repo, src.Ref, src.Subdir)
	if err != nil {
		fmt.Fprintf(stderr, "tmpl: %v\n", err)
		if errors.Is(err, fetch.ErrNotFound) {
			return exitNotFound
		}
		return exitFail
	}
	tw := tabwriter.NewWriter(stdout, 0, 0, 3, ' ', 0)
	for _, e := range catalog.List(res.Files) {
		fmt.Fprintf(tw, "  %s\t%s\n", e.Name, e.Description)
	}
	tw.Flush()
	return exitOK
}

// isTerminal reports whether f is an interactive terminal (a character device).
func isTerminal(f *os.File) bool {
	fi, err := f.Stat()
	return err == nil && fi.Mode()&os.ModeCharDevice != 0
}
```

````markdown
# tmpl

Start new projects from templates with one command.

```sh
brew install wsoule/tap/tmpl
tmpl pierre my-app
```

## Usage

```
tmpl <source> [dest]   copy a template into dest (default ".")
tmpl list              list templates in the default repo
tmpl version
```

`<source>` can be:

| Source | Example |
|---|---|
| A template name | `tmpl pierre` → `templates/pierre` in `wsoule/tmpl` |
| A GitHub repo or folder | `tmpl alice/templates/web@v2` |
| A local directory | `tmpl ./my-template`, `tmpl ~/templates/web` |

Flags: `-n/--name` sets the project name, `-f/--force` overwrites existing
files, `--no-setup` skips the Claude handoff, and `-y/--yes` never prompts.

Existing files are never overwritten unless you pass `--force`, so it's safe
to run in a folder that already has things in it.

## Use your own templates

Make a repo with a `templates/` folder (one subfolder per template), then:

```sh
export TMPL_REPO=you/your-templates
tmpl list
tmpl web my-app
```

Or skip the env var and use the full path: `tmpl you/your-templates/templates/web`.

### Template features (all optional)

- **`{{name}}`** anywhere in a text file is replaced with the project name.
  The default is the folder name, lowercased and made package-safe.
- **`tmpl.json`**: `{ "description": "…" }`, shown by `tmpl list`. It is never
  copied into projects.
- **`.agents/skills/setup/SKILL.md`**: plain-English setup steps. After
  copying, `tmpl` offers to start [Claude Code](https://claude.com/claude-code)
  in the project to follow them.

`.git`, `node_modules` and `.DS_Store` are never copied. Private repos work if
`GITHUB_TOKEN` is set or you're logged in with `gh`.

## Install

```sh
brew install wsoule/tap/tmpl
# or
go install github.com/wsoule/tmpl/cmd/tmpl@latest
```
````
